# PrettyBiddyBeauty Website

This is a launch-ready static website for PrettyBiddyBeauty.

## Important before launch

Open `index.html` and replace:

1. The Booksy button link:
   - Find `https://booksy.com/`
   - Replace it with your exact Booksy booking link.

2. The photo placeholders:
   - The current design uses elegant placeholders so the site still looks finished.
   - Add your real photos later by placing them in an `images` folder and replacing each placeholder block with an `<img>` tag.

3. Your exact studio address, phone number, and business hours when ready.

## Upload to GitHub

1. Unzip this folder.
2. Open your empty GitHub repository.
3. Click **uploading an existing file**.
4. Open this unzipped folder.
5. Select all three website files:
   - `index.html`
   - `styles.css`
   - `script.js`
6. Drag them into GitHub.
7. Scroll down and click **Commit changes**.

Do not upload the outer ZIP file by itself. Upload the files inside the unzipped folder.

## Turn on GitHub Pages

1. Open the repository's **Settings**.
2. Click **Pages** in the left menu.
3. Under **Build and deployment**, select:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/ (root)`
4. Click **Save**.
5. Wait 2–5 minutes. GitHub will show your live website link.

## Files

- `index.html` — website content
- `styles.css` — colors, layout, and mobile design
- `script.js` — mobile menu and copyright year
